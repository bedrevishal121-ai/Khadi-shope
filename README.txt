SOHALA KHADI WEBSITE
1. Upload index.html, admin.html and data.json together to your GitHub repository.
2. Open index.html for the public storefront.
3. Open admin.html to edit products/store/reviews in this browser.
4. Admin edits are browser-local. To publish changes for all visitors, click Export data.json in admin, replace repository data.json with exported file and commit it.
5. Static GitHub Pages does not provide secure admin authentication or cross-user database storage. For true secure shared admin, connect Firebase/Supabase and protect access rules.
